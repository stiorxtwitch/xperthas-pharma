Guide d'utilisation CHL

Bienvenue sur le système de gestion des stocks du Centre Hospitalier de Liège. Ce guide vous explique comment vous connecter, naviguer entre les sections, et surtout comment déclarer correctement chaque mouvement de stock.

🔐
Se connecter au système
1

Entrez votre pseudo Discord

Sur la page de connexion, saisissez votre pseudo Discord exact (celui que vous utilisez sur le serveur CHL). Attention, la recherche est sensible à la casse et aux espaces.

2

Cliquez sur "Envoyer le code par DM"

Le bot CHL vous enverra automatiquement un code à 6 chiffres en message privé Discord. Assurez-vous que vos messages privés sont ouverts aux membres du serveur.

⚠️
Code valable 10 minutes
Le code expire après 10 minutes. Si vous ne l'avez pas reçu ou qu'il a expiré, cliquez à nouveau sur "Envoyer le code".
3

Récupérez le code dans vos DM Discord

Ouvrez Discord → Messages privés → Bot CHL. Vous verrez un message avec votre code. Ne partagez jamais ce code avec quelqu'un d'autre, il est personnel et à usage unique.

🚫
Ne partagez jamais votre code
Ce système existe pour éviter l'usurpation d'identité. Chaque action est tracée et liée à votre compte Discord.
4

Saisissez le code et connectez-vous

Entrez le code reçu dans le champ prévu, puis cliquez sur "Se connecter". Vous serez automatiquement redirigé vers le tableau de bord du stock Pharmacie.

✅
Connexion confirmée sur Discord
À chaque connexion réussie, un message est automatiquement posté dans le canal de log Discord avec votre nom et l'heure.
🗺️
Naviguer dans l'application

Après connexion, vous arrivez sur la page Stock Pharmacie. C'est la zone principale de gestion des médicaments et équipements pharmaceutiques.

Le bouton "Salle de soin →" en haut de page vous permet de basculer vers le stock de la Salle de soin, et inversement.

Le bouton "Déconnexion" en haut à droite vous déconnecte et efface votre session. Vous devrez vous reconnecter via le code Discord à votre prochaine visite.

Les quantités affichées sont sauvegardées localement dans votre navigateur. Si vous changez d'appareil ou videz votre cache, le stock repart à 0 localement — mais les logs Discord restent intacts.

📦
Gérer le stock
1

Repérez le produit concerné

Parcourez le tableau et trouvez l'article que vous souhaitez modifier. Les quantités à 0 sont affichées en rouge pour signaler une rupture de stock.

2

Cliquez sur "+ Ajouter" ou "− Retirer"

Une fenêtre s'ouvre pour vous demander la quantité. Saisissez un nombre entier positif. Vous pouvez valider avec Entrée ou annuler avec Échap.

3

Confirmez l'action

Cliquez sur "Ajouter" ou "Retirer" selon l'action. Un écran de chargement apparaît brièvement, puis une notification latérale confirme que le stock a été mis à jour et que le log a été envoyé sur Discord.

ℹ️
Log automatique sur Discord
Chaque action (ajout ou retrait) génère un message dans le canal de log Discord avec votre nom, le produit, la quantité et le lieu concerné.
📍
L'importance des lieux

Le système distingue deux zones de stock distinctes. Il est impératif d'effectuer votre action sur la bonne page selon l'endroit physique où vous vous trouvez ou d'où provient le matériel. Chaque retrait ou ajout est horodaté et associé au lieu déclaré.

💊
Pharmacie
Zone de stockage principal des médicaments, poches de sang, injecteurs et équipements pharmaceutiques. Accès via la page Stock Pharmacie.
Page home1.html
🏥
Salle de soin
Zone opérationnelle de soins directs aux patients. Bandages, kits chirurgicaux, dispositifs d'urgence. Accès via la page Stock Salle de soin.
Page home2.html
🚨
Ne jamais déclarer dans la mauvaise zone
Si vous retirez un garrot de la Salle de soin mais que vous le déclarez sur la page Pharmacie, le log Discord sera incorrect et les stocks seront faussés. Soyez toujours sur la bonne page avant d'agir.
📋
Règles à suivre

Déclarez immédiatement tout mouvement de stock au moment où il se produit. Ne pas attendre la fin de service pour regrouper plusieurs actions.

Vérifiez que vous êtes sur la bonne page (Pharmacie ou Salle de soin) avant tout ajout ou retrait. Le lieu est enregistré de façon permanente dans les logs.

Ne communiquez jamais votre code de connexion à un collègue. Chaque membre du personnel doit utiliser son propre compte Discord pour se connecter.

En cas d'erreur de quantité, effectuez une action corrective inverse (ex : si vous avez retiré 10 au lieu de 5, rajoutez 5) et signalez-le dans le canal Discord prévu.

Déconnectez-vous après chaque session, surtout si vous utilisez un poste partagé. Le bouton "Déconnexion" se trouve en haut à droite de chaque page.

En cas de bug ou problème (code non reçu, erreur serveur, quantité incorrecte), contactez un responsable directement sur le serveur Discord CHL.
